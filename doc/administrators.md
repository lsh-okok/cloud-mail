# 超级管理员

以现有超级管理员登录，打开「用户列表」，对已启用的用户选择「操作 → 设为超级管理员」并确认。用户重新登录后即可管理整个站点；账号仍使用原邮箱和密码。可同时保留多位超级管理员，无需修改配置或重启服务。新账号先通过用户列表添加，或使用已注册的账号。

「取消超级管理员」只撤销管理身份，不删除用户、邮箱和邮件。用户恢复其原有权限身份，必须重新登录；取消自身身份会退出当前登录。系统禁止撤销最后一位可登录的超级管理员。停用、删除或修改管理员的普通权限身份之前，需要先取消其超级管理员身份。具有用户管理权限的普通用户不能更改超级管理员账号。

将初始账号 `admin@cloudmail.test` 替换为自己的账号时，先授予自己的账号超级管理员身份，用另一浏览器会话确认能够登录并访问管理页面，再取消初始账号的超级管理员身份。之后可按用户管理功能处理初始账号；这不会把该账号的邮箱和邮件自动转给新管理员。

首次安装或首次升级到此功能时，`ADMIN_EMAIL` 指定的已有账号自动成为初始超级管理员。之后以数据库保存的管理员身份为准：修改 `ADMIN_EMAIL` 不会授予其他用户管理权限，重启也不会重新创建或授权已撤销的初始账号。普通权限身份的名称和编号不会授予超级管理员身份，只有现有超级管理员能够执行专门的授权操作。

授权变更、审计和目标账号登录失效在同一事务内完成。取消管理员身份也会使站点旧的公共集成令牌失效，仍需使用时由现有管理员重新生成。

升级使用数据库迁移 6，新增管理员成员及初始化状态表，保留现有用户、密码、邮箱、邮件和域名。旧程序不能直接读取升级后的数据库；回退应恢复升级前配套的数据库、附件、配置及镜像。
