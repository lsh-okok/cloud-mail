# 批量创建邮箱

“主邮箱管理 → 批量创建邮箱”支持随机前缀、连续编号，以及粘贴或导入 UTF-8 TXT 名单。每份名单去重后最多 1000 个地址，完整地址可以混用受控域名；未带域名的前缀使用表单中选择的域名。

预览通过后，页面固定当前名单，每 100 个地址提交一次。创建结果按原名单顺序展示，可复制或导出新增和已存在的地址。单个地址校验失败不会影响其他地址；网络中断时暂停后续提交，“重试并继续”使用原名单确认未返回结果的地址，再继续尚未提交的批次。“重试失败项”会重试失败、待确认及尚未提交的地址，已成功项保留。

邮箱归当前管理员所有，不增加登录用户，不生成登录密码，也不自动生成子邮箱取信链接。创建后自动刷新主邮箱和收件箱邮箱列表。关闭弹窗会保留当前页面中的名单和结果；离开或刷新页面会丢失这份临时进度，已创建的邮箱会保留。创建期间应保持页面打开。

## 接口

`POST /api/admin/mailboxes/batch`，使用现有管理员登录、CSRF 和同源验证，仅主节点可写。配置站点路径前缀时，沿用现有 API 根路径。

请求只接受 `emails` 字段，数组原始长度为 1～100，元素必须是字符串，请求体最多 64 KiB。

```json
{"emails":["test001@example.com","test002@example.com"]}
```

成功处理请求返回 HTTP 200，即使存在逐项失败：

```json
{
  "data": {
    "items": [
      {"email":"test001@example.com","status":"created","mailboxId":"主邮箱 ID"},
      {"email":"test002@example.com","status":"failed","error":{"code":"LOCAL_ACCOUNT_UNAVAILABLE","message":"该地址已属于其他用户，或邮箱已停用、删除。"}}
    ],
    "created": 1,
    "existing": 0,
    "failed": 1
  }
}
```

地址按现有邮箱规则规范化并去重，结果保留首次出现顺序；基础邮箱先于 `+tag` 邮箱创建。已存在的主邮箱返回 `existing`，保留公开标识、收件范围、启停状态和取信链接；管理员已有的可用邮箱可关联为主邮箱，其他用户或已停用、删除的本地邮箱返回失败。

每个请求使用一个事务，逐项创建使用保存点。预期地址错误只回滚当前地址；内部数据库错误回滚当前请求，先前已完成的请求保留。重复提交相同地址不会重复创建邮箱，无需数据库迁移。
