# 邮箱验证与只读节点

用户确认范围：MX/本地来源、子邮箱独立链接、邮箱验证和节点管理。Outlook/iCloud 读取、卡密兑换不在本次范围。原需求副本保留不变。

## 使用

- “主邮箱管理 → 添加主邮箱”：输入前缀、选择接收域名，自动创建管理员持有的本地邮箱并关联来源；已有本人有效邮箱可直接关联。他人的、停用及已删除地址不能被接管。账号与来源、审计、同步事件同事务提交，失败不留下半份数据。
- “邮箱验证 → 验证来源”：从当前链接同步，保留自定义 URL；同一完整地址出现多份来源/平台策略时提示冲突。系统模式直接复用本地公开读取策略；链接通过只说明内部取信策略可用。
- “验证任务”：选择主邮箱和抽样数量；最多4个活动任务、每任务20000项、原始选择数组最多500个ID。任务/明细/标识/发送意图持久化，可停止、复检并下载完整 CSV。
- “SMTP 发件配置”：与原邮件发送通道独立。填写默认发件人或发件池及授权码；只支持 TLS 或强制 STARTTLS，证书验证和 TLS1.2 下限始终启用。发件池存在时不回退默认账号。授权码加密保存，响应不返回密文或明文。
- “实际收信”：确认后发送随机标识，只有该子邮箱公开读取结果包含本次标识才通过。所有任务共用串行发送队列与间隔，池账号轮换。SMTP 接受不确定、网络异常和未到信均保留待确认结果；复检沿用原标识，绝不重发。服务重启把未结束任务标为中断，不自动续发。
- “每日验证计划”：默认停用，02:00、全部主邮箱、每邮箱抽样1；使用系统设置时区（默认 Asia/Shanghai）。启用需要明确确认发信，每15秒检查，当地日期只认领一次；手动执行仅使用已保存参数。
- “节点管理”：创建后仅本次显示接入凭据和配置下载。启停可恢复；撤销永久失效，撤销后才能删除记录。在线依据15秒心跳；就绪要求同步追平，二者分别显示。

## 运行结构

数据库有序升级到 migration4。主节点继续使用现有 SQLite 单写进程锁；新增任务/日期事务与串行队列不能据此宣称支持多个可写主进程。

子节点使用独立数据目录、JWT 和数据加密密钥，不初始化管理员，不运行 SMTP/LMTP/维护任务。已使用的数据目录记录角色，拒绝原地主子切换。独立 Compose 模板为 `docker-compose.replica.yml`；复制 `.env.replica.example` 为受保护的 `node.env`，填入一次性凭据后：

```sh
docker compose --env-file node.env -p cloud-mail-replica -f docker-compose.replica.yml up -d
```

节点只接收白名单来源、平台、链接摘要和设置。固定快照每页1000条、有效15分钟、绑定节点和主进程；主管理数据以密文物化快照。子节点保存 staging 页进度，完整后事务安装，再消费连续增量；增量最多500条且限16MiB、事件保留30天，缺口或过期重建快照。

每5秒同步。网络失败超过120秒关闭就绪；明确401/403立即关闭。重启一律先未就绪。MX 邮件留在主节点，子节点每次通过受控中继读取，主管理端核对完整收件人、真实链接、平台、策略指纹和当前节点状态；缓存、游标和正文返回前仍进行最终复核。子节点不暴露旧管理/邮件/附件 API。

主节点 `health/live` 为存活，`health/ready` 要求邮件服务就绪；子节点就绪取决于共享同步状态。停机先停止接收新 HTTP，取消并等待验证工作及同步/中继，再关闭邮件服务和数据库。

## 配置与验证边界

主节点需要原有 `DATA_ENCRYPTION_KEY` 才能保存发件授权码、创建受保护快照。禁止用示例文件覆盖部署密钥。自定义 HTTP 逐跳检查全部 DNS 地址并固定连接目的地，禁止私网、限5次重定向/2MiB响应；SMTP 默认同样限制目的地，仅可通过 `VERIFICATION_SMTP_ALLOW_CIDRS` 显式放行受控内网地址，仍验证证书。子节点主地址默认 HTTPS；局域网 HTTP 必须明确 `NODE_ALLOW_INSECURE_HTTP=true`。

自动化回归覆盖实际本地邮件存储读取、20000项边界、幂等/停止/重启/不重发、TLS/socket取消、SSRF/重定向、每日认领、报告校验，以及5001链接快照恢复、连续增量、节点停用/撤销竞争、缓存/游标/正文最终复核、角色与旧 API 隔离。界面构建、LAN HTTP 的复制与 SHA-256 下载校验回退也完成验证。具体数量与部署联调结果见部署记录。

尚未完成原方案提出的100000链接、200并发持续10分钟性能验收、跨服务器故障演练及既有业务迁移；本次不把这些记录为通过。配置真实 SMTP 发件账号后，用户可在页面执行对其目标邮箱的实际收信测试；自动计划保持停用。
