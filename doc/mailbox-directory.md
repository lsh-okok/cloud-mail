# 收件箱与主邮箱目录

管理员在收件箱添加的本地邮箱会同时登记到主邮箱管理；从主邮箱管理或批量创建添加的邮箱也会出现在该管理员的收件箱。普通用户的邮箱不会自动纳入管理员取信目录。

启动应用及加载主邮箱列表时，会补齐已有管理员的可用本地邮箱。补齐仅限受控域名，已停止域名中的历史账号也可补齐；新建邮箱仍要求域名启用。补齐不受后来设置的前缀长度和禁用词影响，不会修改原有主邮箱的公开标识、启停状态、收件范围、链接或邮件。

收件箱账号负责本地收信，主邮箱的“公开取信”开关控制公开子邮箱链接。关闭公开取信后，收件箱仍正常收信；停用本地账号则同时阻止其公开取信，管理页显示“邮箱已停用”。

删除本地邮箱后，两个邮箱列表均不再显示该账号，其公开链接不可读取。软删除保留主邮箱配置和链接，恢复原账号后使用原有标识及策略。物理删除后重建同地址邮箱会生成全新的主邮箱身份，并清理原账号的公开链接及发送同步删除事件，旧链接不会转交给新账号。域名范围的主邮箱配置独立保留。

账号创建、主邮箱关联、审计和同步事件在同一数据库事务内提交。历史补齐可重复执行，已有关系不会重复生成审计或同步事件。
